Cyrene uses two separate connections. It helps to know which is which:

Discord {{ both_ways() }} website

Proves to the website which Discord user you are, so it can show your accounts and nobody else's. You do this once per browser.

Cyrene {{ both_ways() }} HoYoLAB

Lets Cyrene read your Genshin data (Resin, roster, events) from HoYoLAB. You can link several Genshin accounts.

{{ topic("connect-discord") }}

Open Connect Discord in the website sidebar, then choose one of these:

  • Sign in with Discord. Authorise Cyrene in the Discord window that opens.
  • Use a code. Copy the code shown on the page and run /verify code:YOURCODE in Discord. Codes expire and work once. If one is rejected, press Generate a new code.

To switch to another Discord account later, use Connect to a different Discord account on the same page. You stay connected as before until the new one succeeds.

{{ topic("link-hoyolab") }}

Run /link-account in Discord, or open Settings and choose Add HoYoLAB account. In Discord you can pick how to sign in:

  1. Discord Login

    Enter your HoYoLAB email or username and password in the form. Your password goes straight to HoYoLAB to sign in, and Cyrene never stores it.

  2. Cookie Login

    For advanced users. Paste your HoYoLAB cookies across two short forms. Adding the optional stoken lets Cyrene refresh the login on its own.

If HoYoLAB asks for extra verification, Cyrene sends a Complete verification link. Once signed in, choose which Genshin account on that HoYoLAB profile to link.

{% call callout("Can't see your characters?", "tip") %} Some data only appears if your Battle Chronicle is public. In HoYoLAB, make your character details visible in the Battle Chronicle settings. {% endcall %} {{ topic("manage-accounts") }}

Run /accounts to see every linked account. Choose one from the menu, then:

  • Add Account links another one.
  • Edit Nickname renames it inside Cyrene, which helps if you have several. It does not change anything in game.
  • Remove Account unlinks it.

You can do the same from Settings on the website, or remove an account by UID with /unlink-account. Removing an account unlinks it from both Discord and the website.

{{ topic("privacy") }}
  • Account pages and commands only ever show accounts linked to your own Discord account.
  • In a server, slash commands about your account reply privately. The prefix versions, such as {{ prefix }}resin, reply in the channel for everyone to see.
  • Your HoYoLAB password is never stored. Saved login cookies are stored encrypted.
