“That verification code is invalid, expired, or has already been used.”

Codes only work once and expire after a while. Go back to Connect Discord, press Generate a new code and run /verify with the new one. Copy it exactly, or sign in with Discord instead.

{{ topic("hoyolab-data") }}
Characters, events or exploration don't show any data

Open HoYoLAB and make sure your Battle Chronicle details are public. Then reload the page. If it still fails, the login may have expired: remove the account in Settings and link it again.

Some of my weapons or materials are missing

HoYoLAB only shares equipped weapons and development materials. Import the rest of your weapons with the Cyrene Scanner, or add copies by hand. Other items, such as artifacts and food, can't be added.

“Cyrene couldn't retrieve your Genshin Resin data from HoYoLAB.”

HoYoLAB might be busy, or your login might have expired. Wait a minute and try again. If it keeps happening, relink the account with /link-account.

{{ topic("commands") }}
Prefix commands don't respond

The server may use a different prefix. Slash commands always work, so try /ping. Server administrators can check or change the prefix with /prefix.

A name with spaces isn't found in a prefix command

For the calculators, wrap the name in quotes, for example {{ prefix }}cr "Hu Tao" 1 90. Slash commands avoid this entirely, because you pick the name from the suggestions.

A command failed and showed an Error ID

Share the Error ID when asking for help, as it points to exactly what went wrong. Server staff with the Manage Server permission can look it up with /error.
