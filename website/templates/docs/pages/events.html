Events brings together everything time-limited in one place:

  • Limited-Time Events, with rewards, countdowns and categories you can hide if you don't care about them.
  • Permanent Events and the endgame modes: Spiral Abyss, Imaginarium Theater and Stygian Onslaught, with your progress for the current cycle.
  • Event Wishes, showing the current and upcoming banners.
  • Custom Events, your own activities and schedules.

Events that haven't opened yet show a countdown to when they become available. Progress and daily resets begin once they open.

{{ topic("tracking") }}

Where HoYoLAB reports it, Cyrene marks events as completed for you. HoYoLAB only reports completion, not whether you have claimed the rewards, so each event also has a manual checkmark. Tick it once you have claimed everything. Unticking it later returns the event to automatic tracking.

Some events can't be tracked automatically on every account. In that case, use the checkmark on its own.

{{ topic("custom-events") }}

Use Create Event to add your own activity, such as a weekly routine or a personal goal. You can add an image (PNG, JPG or WebP, up to 2 MB).

{% call callout("Several accounts?") %} Creating a custom event for several accounts makes a separate copy for each one. Edits, progress and deletion then stay with that account. {% endcall %} {% endblock %}
