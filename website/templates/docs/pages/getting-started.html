Cyrene helps you keep on top of Genshin Impact without opening the game. It comes in two parts that work together:

The Discord bot

Quick lookups for characters, weapons and enemies, live Resin and Expedition checks, and reminders that ping you.

The website

A bigger space for planning: your character roster, a materials planner, events, wish history, achievements and automatic code claiming.

Lookups such as /character work for everyone straight away. Anything about your account, such as Resin or your roster, needs a linked Genshin account.

{{ topic("setup") }}

  1. Add Cyrene to Discord

    Add the bot to a server you manage, or join the Cyrene Discord server to use it there.

  2. Connect Discord to the website

    Open Connect Discord in the sidebar. Either sign in with Discord, or copy the code shown and run /verify with it. This tells the website who you are.

  3. Link your Genshin account

    Run /link-account in Discord, or use Add HoYoLAB account in Settings. Either way, the account appears in both places.

{% call callout("That's it", "tip") %} Try /resin in Discord, or open Characters on the website to see your roster. Connecting your accounts explains each step in more detail. {% endcall %} {{ topic("using-commands") }}

Type / in Discord to see Cyrene's commands. When a command needs a name, such as a character or weapon, start typing and pick from the suggestions so the spelling is always right.

Most commands also have a shorter text version that starts with a prefix. The default prefix is {{ prefix }}, so {{ prefix }}c Furina does the same as /character character:Furina. Server administrators can change the prefix with /prefix. Each command in this guide lists its prefix shortcuts.
