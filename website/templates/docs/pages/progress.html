{% extends "docs/layout.html" %} {% from "docs/macros.html" import topic, callout with context %} {% block docs_body %} {{ topic("wishes") }}

Wishes shows your full wish history across the Character Event, Weapon Event, Standard and Chronicled Wish banners, with stats for each one. Switch between grid and list views, and filter by rarity.

To import your history, use the Cyrene Scanner's Wish Scanner to copy your wish history URL, then press Import and paste it.

{% call callout("Is the URL safe to paste?") %} The URL contains a temporary key. Cyrene uses it once to import your history and never stores it. {% endcall %} {{ topic("achievements") }}

Achievements lists every achievement by category, with your progress. Filter by version, add your own notes to any achievement, and press Import to load your progress from an exported JSON file.

{{ topic("exploration") }}

Exploration shows your exploration progress for each region, straight from HoYoLAB. Switch between grid and list views, or expand everything at once.

{{ topic("inventory") }}

Inventory lists your development materials, synced from HoYoLAB. The page loads straight away and fills in as the sync finishes.

{% call callout("Why are some items missing?") %} HoYoLAB only shares development materials. Artifacts, food, gadgets, quest items and a few materials, such as Dream Solvent and Adventurer's Experience, aren't included. {% endcall %} {% endblock %}
