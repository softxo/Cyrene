Codes lists the gift codes that are currently active. Choose an account and claim a code with one press, without copying it into the game.

Turn on Automatic Claiming and Cyrene checks for new codes and tries to redeem them for that account. It is off by default and set per account, so turn it on for each account you want.

{{ topic("daily-check-in") }}

The HoYoLAB daily check-in gives free rewards each day. Turn on Daily Check-In on the Codes page and Cyrene claims it for you automatically.

{{ topic("reminders") }}

Reminders send you a message in Discord when something in game is ready. Set them up on the Reminders page with Add Reminder, with /reminders in Discord, or with the buttons under /resin.

Reminder Tells you when
Resin Your Resin reaches the amount you choose, from 1 to 200.
Expeditions One of your Expeditions finishes.
Serenitea Pot Your Realm Currency is ready to collect.
Parametric Transformer The Parametric Transformer is ready to use again.
Custom At a time you set yourself.
{% call callout("Reminders belong to the Genshin account") %} Reminders are shared per Genshin account. Notifications go to every Discord account currently linked to it. {% endcall %} {{ topic("reminder-modes") }}

Manual

Fires once, then switches itself off. Good for a one-off, such as Resin before a domain run. Set it again whenever you need it.

Automatic

Stays on. After it fires, it re-arms and fires again the next time the condition is met. Good for “always tell me when my Resin is nearly full”.
